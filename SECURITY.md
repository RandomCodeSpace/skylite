# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability
reporting: open the repository's **Security** tab and choose
**Report a vulnerability**, or go directly to
https://github.com/RandomCodeSpace/skylite/security/advisories/new.

Do not open public issues, pull requests or discussions for vulnerabilities.

## Supported versions

skylite has no released versions yet. Only the `main` branch is supported, and
fixes land there.

## What to include

- A description of the vulnerability and its impact.
- Steps or code to reproduce it.
- The commit or `skylite version` output you tested against.
- Any suggested fix or mitigation, if you have one.

## Response

skylite has a single maintainer, so responses are best-effort. Reports are
acknowledged and handled as quickly as possible, but there is no guaranteed
response time. Please allow time for a fix before disclosing publicly; the
advisory will credit you unless you ask otherwise.
